# Bora De Delivery — Padrões do Projeto

O Bora De Delivery é um sistema web de autoatendimento para lancherias/restaurantes, inspirado na experiência dos totens do McDonald's.

O Bora De Delivery deve parecer:
- rápido
- premium
- moderno
- extremamente simples de usar

O código deve parecer:
- profissional
- organizado
- escalável
- fácil de manter
