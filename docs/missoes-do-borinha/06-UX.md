# 06 — UX: Experiencia do Usuario

## 6.1 Fluxos Principais

### Fluxo 1: Novo Usuario — Primeira Experiencia
1. Usuario faz cadastro/login
2. GamificationProvider detecta primeiro login
3. Cria GamificationProfile (nivel 1, 0 XP, 0 coins, streak 1)
4. Atribui primeiras 3 missoes diarias
5. Exibe toast: "Bem-vindo! Complete missoes para evoluir!"
6. Badge de streak aparece com "Fogo 1"
7. Usuario ve missoes na tela /missoes

### Fluxo 2: Usuario Retornando — Login Diario
1. Usuario abre app
2. GamificationProvider.onUserLogin() chamado
3. StreakService.processLogin():
   a. Verifica lastLoginDate (serverTimestamp)
   b. Se ontem -> streak +1
   c. Se hoje -> ignora
   d. Se antes -> reset para 1
4. Verifica recompensas de streak (3, 7, 14, 30... dias)
5. Se milestone -> award coins + badge + toast
6. Verifica se missoes diarias/semanais expiraram
7. Se sim -> MissionService.assignDailyMissions() / assignWeeklyMissions()

### Fluxo 3: Completar Missao
1. Usuario realiza acao (ex: avalia pedido)
2. Sistema existente processa avaliacao
3. Hook chama POST /api/gamification/actions { action: "reviewed" }
4. Servidor:
   a. Award XP (50 base + bonus)
   b. MissionService.updateProgress("reviewed", 1)
   c. Verifica cada missao ativa com action "review"
   d. Incrementa progresso
   e. Se threshold atingido -> status = "completed"
5. Resposta: { xpEarned, missionsUpdated, coinsEarned }
6. Cliente:
   a. XpEarnAnimation (+60 XP)
   b. Se missao completada -> MissionCompletedToast
   c. XpBar atualiza (animacao)
   d. Se level up -> LevelUpOverlay

### Fluxo 4: Resgatar Recompensa de Missao
1. Usuario ve missao "completed" na tela /missoes
2. Clica em "Resgatar"
3. POST /api/gamification/missions/:id/claim
4. Servidor:
   a. Valida missao "completed" e nao expirada
   b. Award XP (mission.rewards.xp)
   c. Award Coins se houver
   d. Se cosmeticId -> addItem ao inventario
   e. status = "claimed"
5. Cliente: animacoes XP + coins, card muda para "claimed" (cinza)

### Fluxo 5: Comprar na Loja
1. Usuario navega para /loja
2. Ve grid de itens com precos, "Saldo insuficiente" onde aplicavel
3. Clica em "Comprar" -> modal de confirmacao
4. POST /api/gamification/shop/purchase { itemId }
5. Servidor:
   a. EconomyService valida caps e limites
   b. Verifica saldo, level requirement
   c. Deduz coins (transacao Firestore atomica)
   d. Se cosmetico: addItem ao inventario
   e. Se cupom: gera codigo BORA_XXX, salva em cupon_resgates
6. Cliente:
   a. Animacao coins voando
   b. CoinsDisplay atualiza
   c. Se cupom: modal com codigo
   d. Se cosmetico: botao "Equipar agora"

### Fluxo 6: Resgatar Cupom Bora no Pedido
1. Usuario no checkout, insere codigo BORA_XXXXX
2. POST /api/gamification/cupons/validate
3. Servidor:
   a. Busca cupom por codigo
   b. Verifica userId dono
   c. Verifica validade (30 dias)
   d. Verifica pedido minimo
   e. Verifica conflitos (sem outros cupons, sem promocoes)
   f. Verifica 7 dias desde ultimo resgate
   g. Valida margem (economyService)
4. Se valido: desconto aplicado
5. Se invalido: mensagem de erro especifica

## 6.2 Estados de Tela

### Loading States
- **Perfil:** Skeleton avatar (circulo) + skeleton XP bar + skeleton stats
- **Missoes:** 3 skeleton cards com shimmer
- **Loja:** Grid de 6 skeleton cards
- **Historico:** Timeline de 5 skeleton items

### Empty States
- **Sem missoes:** Borinha ilustracao + "Suas missoes estao sendo preparadas!"
- **Loja vazia:** "Nenhum item disponivel no momento."
- **Historico vazio:** "Comece a usar o Bora para ver seu historico!"
- **Inventario vazio:** "Complete missoes e junte coins para desbloquear itens!"

### Error States
- **Falha perfil:** Card erro + "Tentar novamente"
- **Falha missao:** Toast erro "Nao foi possivel completar a missao."
- **Falha compra:** Toast erro com motivo especifico
- **Falha cupom:** Mensagem abaixo do campo com razao especifica

| Conflito cupom | "Nao e possivel usar dois cupons no mesmo pedido." |

| Cupom outro user | "Este cupom pertence a outra conta." |
| Cupom ja usado | "Este cupom ja foi utilizado." |
| Cap diario coins | "Limite diario de Bora Coins atingido. Continue amanha!" |
| Cap mensal coins | "Limite mensal de Bora Coins atingido." |
| Missao expirada | "Esta missao expirou. Novas missoes disponiveis!" |

## 6.4 Microinteracoes
1. **Barra de XP:** preenchimento com easing 0.5s, contador animado
2. **Coins:** icone treme + numero com scale 0.3s ao ganhar/gastar
3. **Streak:** badge de fogo com animacao de chama 2s ao subir
4. **Missao completada:** card scale 1.0->1.02, borda verde com transicao de cor
5. **Botao Resgatar:** loading spinner -> checkmark animado
6. **Compra loja:** moedas "voam" do saldo ate o card (trajetoria curva)
7. **Level Up:** overlay fade+scale 0.3s, Borinha pulando (loop)
8. **Notificacao:** badge vermelho com missoes completadas nao resgatadas

## 6.5 Acessibilidade
- Cards de missao: role="button", navegaveis por teclado
- Cores + icones + texto (nao so cor)
- Animações respeitam `prefers-reduced-motion`
- Toast messages: role="alert"
- Textos alternativos em icones e avatares
- Contraste minimo WCAG AA
- Foco visivel em elementos interativos
